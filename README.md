# Assam Inventory Management

This is a responsive JavaScript inventory-management prototype matching the supplied dashboard design.

## Features
- Dashboard
- Party management
- Product / stock master
- Automatic closing stock calculation
- Purchase entry
- Sales / invoice entry
- Stock register
- Reports
- CSV export
- Print report
- Local browser storage
- Responsive layout

## Run
Open `index.html` in a browser.

## Deploy to Vercel
Upload this folder as a static project or connect it to a Git repository.

## Important
This version stores data in browser localStorage. For a production multi-user system, connect the application to a real database and secure authentication/API endpoints.


## Login

This version includes a client-side demo login.

Username: `admin`
Password: `password`

The selected financial year is stored in the browser session.

Important: this is suitable for a prototype/static Vercel deployment. For production multi-user authentication, use a backend API, hashed passwords, sessions/JWT, and a database.
